# English First Words

Небольшое офлайн-приложение для первых английских слов: карточки с переводом на русский, транскрипцией, подсказкой произношения, озвучкой и короткими проверочными заданиями.

Проект сделан как статическая PWA, поэтому его можно открыть из обычного браузера, положить на GitHub Pages или запустить локально для iPad в домашней сети.
https://dirty-fish.github.io/english-first-words/ 
## Что умеет

- показывает слова по темам: животные, семья, еда, цвета, тело, действия, чувства, дом, природа, одежда, числа, предметы, игрушки, школа, признаки и предлоги;
- озвучивает английские слова, фразы и предложения через `speechSynthesis`;
- показывает IPA-транскрипцию и русскую подсказку произношения;
- собирает слово в простую "лестницу": слово, фраза, короткая сцена;
- для глаголов показывает примеры в настоящем, прошедшем и будущем времени;
- дает две практики: выбрать английское слово по русскому переводу и выбрать карточку на слух;
- сохраняет выученные слова в `localStorage`;
- кэширует файлы через service worker и может работать офлайн после первого запуска с сервера.

## Быстрый запуск

Самый простой вариант на этом Mac:

```bash
./start-ipad.command
```

Скрипт найдет свободный порт из диапазона `4174-4180`, покажет адрес вида `http://<ip-mac>:4174/index.html` и запустит локальный сервер. Открой этот адрес на iPad, пока Mac и iPad находятся в одной Wi-Fi сети.

Для запуска вручную:

```bash
python3 -m http.server 4174 --bind 0.0.0.0
```

Потом открой:

```text
http://127.0.0.1:4174/index.html
```

На iPad вместо `127.0.0.1` нужен IP-адрес Mac в локальной сети.

## Установка на iPad

1. Запусти `./start-ipad.command`.
2. Открой показанный адрес в Safari на iPad.
3. Нажми "Поделиться" -> "На экран Домой".
4. Открой приложение с домашнего экрана.

После первого открытия приложение кэширует основные файлы. Если что-то обновилось, нажми кнопку "Обновить приложение" внизу экрана.

## Где что лежит

- `index.html` - разметка приложения.
- `styles.css` - внешний вид и адаптивная верстка.
- `app.js` - словарь, карточки, озвучка, проверки и прогресс.
- `sw.js` - service worker для офлайн-режима.
- `manifest.webmanifest` - настройки PWA.
- `icon.svg` - иконка приложения.
- `start-ipad.command` - локальный запуск для iPad.

## Как добавлять слова

Основной словарь находится в `app.js` в объекте `lessons`.

Минимальная карточка слова выглядит так:

```js
{ en: "cat", ru: "кошка", ipa: "/kæt/", hint: "кэт", picture: "CAT" }
```

Для коротких фраз и предложений добавь запись в объект `chunks`:

```js
cat: ["a cat", "кот", "The cat sleeps.", "Кот спит."]
```

Для глаголов с примерами времен добавь запись в `verbTenses`:

```js
sleep: {
  present: ["I sleep", "я сплю"],
  past: ["I slept", "я спал"],
  future: ["I will sleep", "я буду спать"]
}
```

## Публикация

Проект не требует сборки. Для публикации достаточно отдать файлы из корня проекта через любой статический HTTPS-хостинг, например GitHub Pages.

Важно: service worker не работает при открытии через `file://`. Для офлайн-режима и установки как PWA приложение нужно открывать через `http://localhost`, локальный сервер в Wi-Fi или HTTPS-хостинг.
